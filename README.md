# Top_10_Companies_Hiring_Analysis
This project is an interactive Tableau Treemap dashboard that identifies the top 10 companies hiring for Data Engineer roles with the Job Title Data Scientist. The dashboard applies multiple filtering conditions to analyze hiring patterns and highlight the largest hiring organizations.

Objective

To visualize and analyze the top 10 companies based on hiring data using a Treemap chart while applying specific business and recruitment filters.


Filters Applied

Role = Data Engineer
Job Title = Data Scientist
Company Size ≥ 10,000
Qualification = B.Tech
Preference = Female
Job Portal = LinkedIn
Posting Date within the dataset range
Contact Person name ends with a vowel
Excluded Asian countries
Excluded countries starting with the letter "C"
Top 10 companies selected based on Company Size
Time-based visibility condition between 3 PM and 5 PM IST, While published to Tableau Public, time-based calculations may behave differently due to server time zone settings and UTC-based processing.


Visualization

Chart Type: Treemap

Marks Used
Color: Country
Size: Company Size
Detail: Company Name


Purpose

The Treemap helps compare the largest hiring companies and understand regional hiring trends through country-based color categorization.

Tools Used

Tableau Public
CSV Dataset
Data Visualization Techniques
Calculated Fields
Filters and Aggregations


Key Insights
Large organizations dominate hiring activity.
USA and Germany contain most of the top hiring companies after applying all filters.
Company size plays a significant role in determining the final Top 10 companies.
Multiple filtering conditions help focus the analysis on a specific hiring segment.


Dataset Source

The dataset used in this project is a self-created CSV dataset prepared for educational and analytical purposes.


Project Purpose

The purpose of this project is to demonstrate data filtering, business analysis, and Treemap visualization techniques using Tableau while identifying leading companies based on hiring criteria.
